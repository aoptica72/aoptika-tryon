# А-Оптика — Telegram-бот виртуальной примерки (тестовая версия)

Код бота находится в `telegram_bot/`, клиентская Telegram Mini App — в корне репозитория (`telegram.html`, `telegram.css`, `telegram.js`). Существующие `index.html` и `test.html` не меняются.

## Что работает

- Фото в Mini App обрабатываются **в браузере**, без загрузки на сервер. Распознавание лица — локальный MediaPipe Face Landmarker (`face_landmarker.task`, `vision_bundle.mjs` и WASM-файлы, уже лежат в репозитории).
- Для Mini App подготовлен `dacchi-34355-front.png` с прозрачными линзами без надписей и видимых через линзы дужек. Это производный файл, полученный из утверждённого оригинала `dacchi-34355.png`. Оригинал **не перезаписывается**. Для контроля есть кнопка «PNG оправы». Скрипт для повторной генерации: `python -m telegram_bot.export_frame`.
- Настройка масштаба, положения, поворота; перемещение пальцем; сравнение до/после; сохранение PNG.
- Telegram-бот принимает селфи после согласия, накладывает ту же маску локально на сервере через MediaPipe Tasks и возвращает JPEG. Данные фото не записываются в БД.
- Кнопки каталога, избранного (в памяти процесса), заявок на консультацию/примерку (при `ADMIN_CHAT_ID`). Цена и наличие не придуманы.

**Ограничения:** маска восстановлена по исходной фотографии (в которой белый фон и видны дужки). До проверки на живых селфи она не является утверждённым прозрачным PNG; результат — только ориентировочная визуализация. Сохранение фото из Mini App в Telegram WebView зависит от платформы; при проблемах откройте страницу во внешнем браузере. 3D-посадка, камера в реальном времени, проверенные остатки, сравнение разных SKU и подключение 1С пока не реализованы.

## Проверить Mini App в браузере

При включённом GitHub Pages: https://aoptica72.github.io/aoptika-tryon/telegram.html

Откройте страницу по HTTPS, отметьте согласие на локальную обработку, выберите селфи и посмотрите результат. Для распознавания нужны модели/WASM из корня репозитория. При недоступности распознавания можно переместить оправу пальцем.

## Запуск Telegram-бота

1. Используйте уже созданного бота «А-Оптика» (@AOptikaTryOnBot, если такое имя подтверждено в BotFather). Повторная регистрация не требуется. Токен нельзя присылать в чат или добавлять в GitHub.
2. Скопируйте `telegram_bot/.env.example` в `.env` в корне репозитория. Укажите `BOT_TOKEN`, `MINI_APP_URL` (HTTPS), `ADMIN_CHAT_ID` (личный/служебный чат, в котором бот имеет право писать), `PRIVACY_URL` (реально опубликованная политика обработки ПД). Пока `PRIVACY_URL` пуст, бот специально блокирует согласие на серверную обработку фото.
3. Запуск через Docker из корня репозитория:

```bash
docker build -f telegram_bot/Dockerfile -t aoptika-telegram .
docker run -d --restart unless-stopped --name aoptika-telegram --env-file .env aoptika-telegram
```

Либо локально Python 3.11:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r telegram_bot/requirements.txt
python -m telegram_bot.app
```

Затем откройте бота и отправьте `/start`. После согласия можно прислать селфи в чат или открыть Mini App. Приложение открывается кнопкой `KeyboardButton(web_app=...)`, что позволяет передавать запросы через `Telegram.WebApp.sendData()` обратно боту.

**Примечание о запуске и законе:** сервер должен быть выбран и настроен с учётом применимых требований 152-ФЗ и локализации ПД. Политику, согласия, сроки удаления и уведомления следует проверить перед обработкой фотографий реальных покупателей. Даже без хранения на сервере фото, отправленные непосредственно в Telegram, остаются в истории Telegram до удаления пользователем. Данные заявки также остаются в служебном Telegram-чате после отправки, пока сотрудник их не удалит. `/delete` очищает только сессионные данные в памяти бота, а не сообщения на серверах Telegram.

## Тесты

```bash
python -m pip install pillow pytest
python -m pytest -q telegram_bot/tests
node --check telegram.js
python -m compileall -q telegram_bot
```

Шесть автотестов проверяют каталожные данные, координаты глаз, синтетическую маску, **прозрачность линз реальной DACCHi 34355** и геометрию наложения. Для полноценной приёмки необходимы реальные селфи с разрешением на использование, проверка Telegram Android/iOS, проверка выдачи заявок и оценка визуального качества фронта оправы. Автотесты **не доказывают** качества посадки на пяти реальных лицах.

**Важно:** заявки с именем и телефоном отправляются только после отдельного согласия на передачу контактов и только при указанном `PRIVACY_URL` и `ADMIN_CHAT_ID`. Имя и телефон передаются сотруднику через Telegram, поэтому перед реальным запуском необходимо проверить соответствие обработки персональных данных требованиям законодательства.

## Каталог

Для добавления новых SKU необходимо предоставить оригинальные фотографии фронта, метаданные и отдельные маски. JSON-файлы `telegram_bot/catalog.json` и `telegram_bot/mask.json` пока описывают только DACCHi 34355, размер 54-17-146 (считан с оригинальной фотографии). Не копируйте маску DACCHi 34355 на другие модели.
