# А-Оптика — Telegram-бот виртуальной примерки

Код бота находится в `telegram_bot/`, Telegram Mini App — в корне репозитория (`telegram.html`, `telegram.css`, `telegram.js`). Существующие `index.html` и `test.html` не затрагиваются.

## Что реализовано

- Mini App открывается из Telegram кнопкой reply-клавиатуры «👓 Примерить очки»; команды `/start` и `/tryon` показывают эту кнопку.
- Фотография, выбранная в Mini App, обрабатывается в браузере. Она не отправляется боту и на сервер А-Оптики. Перед выбором фото приложение запрашивает локальное согласие.
- Распознавание лица выполняется локально MediaPipe Face Landmarker (`face_landmarker.task`, `vision_bundle.mjs`, WASM).
- Утверждённая DACCHi 34355 строится из исходной фотографии `dacchi-34355.png` по `telegram_bot/mask.json`. Маска получена из принятого пользователем альфа-канала; геометрия едина для браузерной и Python-версии. Оригинал не перезаписывается.
- Масштаб, смещение, поворот, перемещение пальцем, сравнение до/после и сохранение результата.
- Кнопка экспорта формирует PNG 3086×1164 с прозрачным фоном. Это 2× экспорт исходной фотографии, а не добавление новых деталей.
- Кнопки «Узнать наличие», «Записаться на примерку» и «Консультация» передают запрос боту. Бот запрашивает отдельное согласие на передачу имени и телефона; при заданных `ADMIN_CHAT_ID` и `PRIVACY_URL` отправляет заявку в служебный чат.
- Избранное и сессии пока хранятся в памяти процесса. Фото, присланные непосредственно в чат, можно обрабатывать отдельно через `/server_photo`, только после публикации политики и отдельного согласия.

## Проверка Mini App

HTTPS-страница: https://aoptica72.github.io/aoptika-tryon/telegram.html

Откройте страницу, отметьте согласие на локальную обработку, выберите фото анфас. Если распознавание лица недоступно, положение оправы можно поправить вручную.

**Важно:** действия «Узнать наличие», «Записаться» и «Консультация» передают данные боту через `Telegram.WebApp.sendData()`; поэтому для полного сценария запускайте Mini App из кнопки reply-клавиатуры в чате с ботом, а не из обычного браузера.

## Запуск существующего бота

1. Используется уже созданный `@AOptikaTryOnBot`; повторная регистрация в BotFather не нужна.
2. На российском сервере скопируйте `telegram_bot/.env.example` в `.env` в корне репозитория. Заполните `BOT_TOKEN` и HTTPS-адрес `MINI_APP_URL`. Для заявок дополнительно заполните `ADMIN_CHAT_ID` и `PRIVACY_URL` — адрес реально опубликованной политики обработки персональных данных.
3. Запустите из корня репозитория:

```bash
docker compose up -d --build
docker compose ps
docker compose logs -f --tail=100
```

Для локального запуска Python 3.11:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r telegram_bot/requirements.txt
python -m telegram_bot.app
```

При запуске бот обновляет список команд BotFather. Команда `/start` сразу показывает кнопку Mini App. Команда `/server_photo` запрашивает отдельное согласие на обработку фотографии, отправленной прямо в чат; пока `PRIVACY_URL` не задан, этот режим отключён.

## Переменные окружения

- `BOT_TOKEN` — токен из BotFather; хранить только на сервере, не добавлять в GitHub.
- `MINI_APP_URL` — HTTPS-адрес Mini App.
- `ADMIN_CHAT_ID` — личный или служебный Telegram-чат для заявок; бот должен иметь возможность писать в него.
- `PRIVACY_URL` — опубликованная политика обработки персональных данных. Без неё бот не принимает контактные заявки и не включает серверную обработку фото.

## Проверки

```bash
python -m pip install pillow pytest aiogram python-dotenv
python -m pytest -q telegram_bot/tests
python -m telegram_bot.export_frame
node --check telegram.js
python -m compileall -q telegram_bot
```

CI дополнительно собирает Docker-образ и проверяет импорты aiogram/MediaPipe.

## Что ещё не реализовано / не принято

- Подтверждённая проверка на пяти реальных лицах и полноценный тест внутри Telegram на Android/iPhone.
- Живая камера/AR при движении головы, 3D-посадка.
- Автоматические остатки и цены из товароучётной системы.
- Постоянное хранилище избранного и заявок; сейчас состояние в памяти бота.
- Каталог других моделей и интеграция с 1С/Optima.

Виртуальная примерка показывает приблизительное визуальное соответствие и не заменяет очную проверку посадки в салоне.
