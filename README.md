# А-Оптика — виртуальная примерочная

Тестовый Telegram-бот и Mini App для примерки утверждённой оправы DACCHi 34355.

- **Telegram-бот:** @AOptikaTryOnBot
- **Mini App:** https://aoptica72.github.io/aoptika-tryon/telegram.html
- **Исходный код и запуск:** [telegram_bot/README.md](telegram_bot/README.md)

Фотография в Mini App обрабатывается локально в браузере. Серверный режим, заявки с передачей контактов и хранение пользовательских данных включаются только после настройки соответствующих переменных окружения и публикации политики обработки персональных данных.
